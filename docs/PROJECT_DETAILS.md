# Project Details

Food Ordering System is a Java console application. Customers can view and search menu items, manage a cart, place orders, print a bill and view order history.

It uses OOP concepts, ArrayList, HashMap, two custom exceptions and an array-based queue.
## Menu Management Testing

The following features were tested:

- Displaying all menu items.
- Searching using uppercase and lowercase names.
- Handling extra spaces in search input.
- Displaying a message when an item is not found.
- Retrieving menu items using their IDs.
- Validating menu item IDs, names, and prices.
- Validating food categories and drink sizes.

All tested menu management features worked as expected.
